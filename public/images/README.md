# Image Assets
Place your photos here:
- `campus-polaroid.jpg` -> Matches `POLAROID_PHOTO_1 = "./images/campus-polaroid.jpg"`
- `special-birthday-photo.jpg` -> Matches `SPECIAL_PHOTO_URL = "./images/special-birthday-photo.jpg"`

If these files are not yet present, the app gracefully displays styled high-definition fallback imagery so no broken image borders ever appear.
