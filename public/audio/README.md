# Audio Assets
Place your background music and voice note files here:
- `background-music.mp3` -> Matches `BACKGROUND_MUSIC_URL = "./audio/background-music.mp3"`
- `special-voice-note.mp3` -> Matches `SPECIAL_VOICE_NOTE_URL = "./audio/special-voice-note.mp3"`

If these files are not yet present, the app automatically runs an authentic ambient Lo-fi acoustic synthesizer and voice note player, ensuring zero broken audio experiences.
